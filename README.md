# Quizily

An E-learning platform for students to test their potential and compete with other users of their course. It has leaderboards, progress and many more.

## Features
1. AI powered mcqs preparation
2. Publish mcqs to public and discover quiz
3. Gamifications which includes coins, achievements, leaderboards, insights, ranking and profile customizations.
4. Premium features like advanced learning unlimited assets, usage and deep insights.
5. Authentications and enhanced security
